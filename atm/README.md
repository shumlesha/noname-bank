## ATM

Представляет собой сервис, имитирующий банкомат. Позволяет начислять и списывать деньги со счетов

### Запросы

1. POST `/api/atm/deposit`

**body**

```json
{
  "amount": "100",
  "accountId": "c2dfd101-a169-4e69-8078-7806c4683683"
}
```

Тело ответа отсутствует, нужен просто для нажатия на кнопку

2. POST `/api/atm/withdrawal`

**body**

```json
{
  "amount": "100",
  "accountId": "c2dfd101-a169-4e69-8078-7806c4683683"
}
```

Тело ответа отсутствует, нужен просто для нажатия на кнопку
